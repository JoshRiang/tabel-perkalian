# Simple Multiplication Table

A web-based multiplication table generator that creates a table based on user-specified size. Perfect for educational purposes and quick calculations.

![Multiplication Table](https://user-images.githubusercontent.com/placeholder/multiplication-table.png)

## Features

- **Interactive Input** - Enter table size with a number input field
- **Dynamic Table** - Automatically generates multiplication table
- **Responsive Design** - Works on mobile and desktop devices
- **Bootstrap 5** - Modern, clean UI with Bootstrap styling

## How It Works

1. Enter the number of rows and columns in the input field
2. Click "update" or the value changes automatically
3. The table updates with the multiplication results

## Tech Stack

- **Frontend**: HTML5, JavaScript (jQuery)
- **UI Framework**: Bootstrap 5

## Project Structure

```
├── index.html     # Main interface
└── main.js        # Table generation logic
```

## Usage

Open `index.html` in any browser. No server required.

## Formula

Each cell (i,j) contains the value: `i × j`
